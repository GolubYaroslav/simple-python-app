## Описание проекта

Простое Flask-приложение с полным CI/CD пайплайном на основе Jenkins.
Демонстрирует автоматическую сборку, тестирование и развёртывание
приложения в несколько окружений.

## Структура проекта
```
simple-python-app/
├── app.py              # Flask-приложение
├── test_app.py         # Юнит-тесты
├── requirements.txt    # Зависимости Python
├── Dockerfile          # Образ Docker
├── Jenkinsfile         # CI/CD пайплайн
└── README.md           # Документация
```

## CI/CD Pipeline

### Этапы пайплайна

| Этап | Описание |
|------|----------|
| Checkout | Клонирование репозитория из GitHub |
| Setup Python | Создание виртуального окружения и установка зависимостей |
| Unit Tests | Запуск автоматических тестов |
| Build Docker Image | Сборка Docker образа приложения |
| Push to Registry | Публикация образа в Docker Hub |
| Deploy to Dev | Развёртывание в окружение разработки (порт 8081) |
| Deploy to Staging | Развёртывание в тестовое окружение (порт 8082) |
| Approve Production | Подтверждение развёртывания в production |
| Deploy to Production | Развёртывание в production (порт 80) |
| Tag Release | Создание Git-тега для релизной версии |

### Параметры запуска

| Параметр | Описание | Значения |
|----------|----------|----------|
| STUDENT_NAME | ФИО студента | строка |
| ENVIRONMENT | Среда развёртывания | dev / staging / production |
| RUN_TESTS | Запускать ли тесты | true / false |

### Окружения

- **dev** — окружение разработки, порт `8081`
- **staging** — тестовое окружение, порт `8082`
- **production** — боевое окружение, порт `80`, требует подтверждения

## Автоматический запуск

Пайплайн автоматически запускается при каждом `push` в ветку `main`
через GitHub Webhook.

## Уведомления

После завершения каждой сборки на email автоматически отправляется
уведомление с результатом — успех или ошибка.

## Технологии

- **Jenkins** — сервер автоматизации CI/CD
- **Docker** — контейнеризация приложения
- **Docker Hub** — реестр Docker образов
- **GitHub** — хранение кода и управление версиями
- **Flask** — веб-фреймворк Python
- **Blue Ocean** — визуализация пайплайна

## Запуск вручную

1. Открыть Jenkins: `http://<IP-сервера>:8080`
2. Перейти в `student-golub-pipeline`
3. Нажать **"Собрать с параметрами"**
4. Выбрать окружение и нажать **"Собрать"**
